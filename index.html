डेमो सिंक मोड

असली Google Sheet में ऑटो-अपेंड करने के लिए अपनी Spreadsheet ID और OAuth2 Access Token दर्ज करें, या तुरंत परीक्षण के लिए डेमो सिंक मोड चालू रखें।

ऑटोमेटेड डेमो सिंक मोड
बिना API कुंजी के बैकग्राउंड सिंक का अनुभव करें

लाइव Google Sheets API पेलोड प्रीव्यू

बैकग्राउंड सिंक वर्कर द्वारा भेजा जाने वाला JSON पेलोड:


      

    


    
    

      

        

          
1. UI + Web Speech + Canvas

          
यूज़र एक्शन पर तुरंत IndexedDB में लिखता है, कैनवस एनिमेशन चलाता है और Web Speech API से नरेशन करता है।

        

        

          
2. IndexedDB + Sync Queue

          
दो ऑब्जेक्ट स्टोर्स: 'records' (मुख्य डेटा) और 'sync_queue' (ऑफलाइन लंबित बदलाव)।

        

        

          
3. Service Worker & Sync

          
ऑफलाइन कैशिंग संभालता है और नेटवर्क लौटते ही 'sync-sheets-queue' टैग से ऑटो-सिंक ट्रिगर करता है।

        

        

          
4. Google Sheets API v4

          
कतार में रखे सभी रिकॉर्ड्स को बैच में Google Sheets में अपेंड कर लोकल स्टेटस अपडेट करता है।
